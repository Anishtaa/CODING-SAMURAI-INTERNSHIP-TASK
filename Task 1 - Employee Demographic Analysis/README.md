# Employee Demographic Analysis

## Objective
Analyze employee demographics to understand distribution across departments, gender split, age distribution, and average salary by department.

## How to use
1. Open `docs/Employee_Demographics_Analysis.xlsx` for visualizations.
2. To reproduce the analysis using Python:
   - Install dependencies: `pandas` and `matplotlib`
   - Run: `python src/analysis_script.py` from the repository root.

## Data
The cleaned dataset is located at `data/hr_employee_data.csv`.
