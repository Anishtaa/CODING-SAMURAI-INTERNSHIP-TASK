# Employee Demographic Analysis

## Project Overview
This repository contains a demographic analysis of employees within a company. The analysis focuses on department distribution, gender split, age distribution, and average salary by department.

## Contents
- `data/hr_employee_data.csv` — cleaned dataset used for analysis.
- `docs/Employee_Demographics_Analysis.xlsx` — Excel workbook with visualizations.
- `docs/Analysis_Report.md` — detailed findings and summary.
- `src/analysis_script.py` — Python script to reproduce the analysis.
- `.gitignore`, `LICENSE`, `README.md` — repository metadata.
