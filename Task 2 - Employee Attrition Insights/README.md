# Employee Attrition Insights

This repository contains a cleaned IBM HR employee attrition dataset and an analysis workbook with visualizations and summary findings.

## Contents
- `data/hr_employee_data.csv` — cleaned dataset used for analysis.
- `docs/Employee_Demographics_Analysis.xlsx` — Excel workbook with cleaned data, summary metrics, pivot-like tables, and charts.
- `docs/Analysis_Report.md` — concise report with findings.
- `src/analysis_script.py` — reproducible analysis script.
- `LICENSE` — MIT license.
- `.gitignore` — recommended ignores for Python projects.

## How to use
Open the Excel workbook in `docs/` for a self-contained analysis. To reproduce the analysis using Python, run the script in `src/`.
